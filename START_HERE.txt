TINY TALE v5 - ADMIN STUDIO UPDATE

This is an UPDATE for your existing project. It reuses your existing product
images and database. Do not create an empty repository or delete the old folder.

1. Extract the ENTIRE ZIP into a new folder in Downloads.
2. Close any local Tiny Tale app windows.
3. Double-click APPLY-UPDATE.bat in the extracted folder.
4. When asked for Repository folder, use your EXISTING folder containing app.py
   and .git. It may be:
   C:\Users\NaveenkumarMathaiya\Downloads\Tiny_Tale_Login_Fix_old
   or C:\Users\NaveenkumarMathaiya\Downloads\Tiny_Tale_Login_Fix
   Use the one where your earlier git push worked. Press Enter if the shown
   default is correct. The updater retains settings, database and Git history.
5. Open Command Prompt in that existing repository folder. Run:

   git status
   git add .
   git diff --cached --stat
   git commit -m "Improve admin navigation, staff access and reports"
   git push origin main

   Check that the staged files contain app.py, management.py, requirements.txt,
   enhancements.py, features.py and static/admin-v5.js + admin-v5.css.
   Do not commit your API key, local credentials or database files.
6. In Render deploy latest commit on BOTH tiny-tale-admin and tiny-tale-store.
   Keep your working Brevo environment values and existing DATABASE_URL.
   No new API key is required. New requirements install during the Render build.
7. Wait until BOTH services are Live. Open each service /health URL and check:
   version: 5.0-admin-studio
8. Open the admin site and press Ctrl+F5 to reload the new scripts/styles.
   Owner login: leave Username blank and use your existing admin password.
9. Administration > Staff accounts > Create staff account > Store keeper.
   Use a unique username and password of at least 12 characters.
   Test that login separately: it must show only stock and product media.

BANNER EXAMPLE
Offer banners > upload Knot Jabla image > destination Knot Jabla > button text
Get Knot Jabla Offer > Save. Choose No button for an image-only offer.
The dropdown creates the product link for you.

REPORTS
Reports & downloads > choose report + From/To dates > Generate report.
View the PDF and download Excel/PDF. Dates use IST. Inventory is current stock,
not historical stock. Test payments are not real revenue.

If no local virtual environment exists, local use requires Python installed.
From the existing project directory run:
   py -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
Then use your existing start-admin.bat / start-store.bat.
Render deployment does not require running the app locally.
