TINY TALE v6 - DESIGN, CUSTOM LINKS AND SCROLLING OFFERS

This ZIP updates your EXISTING project. Keep the old Git folder, database,
product images and working Brevo settings. Do not start an empty repository.

1. Extract the ENTIRE ZIP into a new folder in Downloads.
2. Close any local Tiny Tale app windows.
3. Double-click APPLY-UPDATE.bat in the extracted folder.
4. Choose the ORIGINAL repository folder containing app.py and .git.
   It may be:
   C:\Users\NaveenkumarMathaiya\Downloads\Tiny_Tale_Login_Fix_old
   or C:\Users\NaveenkumarMathaiya\Downloads\Tiny_Tale_Login_Fix
   Use the folder where your previous git push worked.
   Press Enter only when the shown default folder is correct.
5. Open Command Prompt IN THAT ORIGINAL Git folder. Run:

   git status
   git add .
   git diff --cached --stat
   git commit -m "Improve store design, banner links and scrolling offers"
   git push origin main

   Check for experience.py, static/experience.css, store-v6.js, admin-v6.js,
   plus the updated app.py, features.py, enhancements.py, store.js and HTML.
   Do not commit your API key, local credentials or database files.
6. Render: deploy latest commit on BOTH tiny-tale-store and tiny-tale-admin.
   Keep the current working Brevo values and shared DATABASE_URL.
   There is no new API key or secret for this release.
7. Wait for both services to be Live. Each /health URL must show:
   6.0-store-experience
8. Press Ctrl+F5 on both websites to reload the new scripts/styles.
9. Owner login: leave Username blank, use your existing admin password.

NEW ADMIN OPTIONS
- Storefront content > Scrolling offer strip: edit messages/optional links,
  choose speed, enable and Publish strip. Refresh the customer store.
- Offer banners > Button destination > Custom URL / store link.
  Examples: /?product=2#collection, #collection, /policies,
  or https://your-website.com/offer
  Keep button text and a destination together, or choose No button.
  Optional: Open button destination in a new tab.
- On a phone, tap Sections to open the admin menu.

NEW CUSTOMER FEATURES
Recently viewed items, clear history, size/price/available-now filters,
gallery thumbnails/previous/next controls, product PIN estimates,
favourites count and free-delivery progress in the bag.
The refreshed design uses cream and teal across both applications.

TEST AFTER DEPLOYMENT
Customer: real OTP email, product size selection, filters, cart, coupon,
PIN estimate and simulated checkout. Admin: keeper login restriction,
stock/media updates, custom banner link, scrolling strip and PDF/Excel report.
Local browser tests use mock email; you still need to verify real delivery.
Payments remain simulated. Full test scope is in VERIFICATION.md.

PREVIEWS contains screenshots from local QA. They show example data,

For local use without an existing virtual environment, install Python and
run from the ORIGINAL project folder:
   py -m venv .venv
   .venv\Scripts\python.exe -m pip install -r requirements.txt
Then use start-admin.bat / start-store.bat.
Render deployment does not require running the app locally.
